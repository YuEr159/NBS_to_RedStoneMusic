普通车道起点布局（Y-Z 截面，可拖拽；单线式参考车道（紫）也可拖 = 其虚拟盒位锚点、直接决定绑定粒子行偏移，MIDI式参考车道为背景、不可拖——其中心基准在下方「参考车道池」的独立窗口中拖拽）

点击标记选中；拖拽移动；选中后可用方向键微调（Shift=大步）；预置模板只重排普通车道

节奏型参考车道池（纯节奏/音高参考，不生成任何物理结构；成员在左侧音轨池勾选「节奏参考」，或直接拖入下方卡片）

勾选音轨池的「节奏参考」→ 默认并入第一条参考车道、放不下自动新建；也可把左侧音轨池的音轨直接拖入卡片（拖入即登记为节奏参考并入该车道，允许重复拖入）；参考车道**不生成任何方块**，只作为粒子特效的节奏/音高参考——想让参考声道同时在普通轨道发声 = 勾选其行内「发声」（建一条普通车道）或把音轨拖入「车道池」卡片；每条参考车道可选类型（单线式/MIDI式，作用于该车道全部成员）——单线式粒子锚定本车道虚拟盒位（起点可在上方「普通车道起点布局」窗口直接拖）、MIDI式锚定轨道 0 CB + 本车道起点基准（本分区下方独立窗口可拖，缺省 (0,0)）再按音高偏移；粒子恒产生（与「发声」无关）；想关闭本车道粒子 = 在下方「粒子特效总览」模块取消该车道的「触发型」勾选

参考车道起点布局（Y-Z 截面，独立窗口；MIDI式参考车道可拖 = 粒子中心基准，单线式为虚拟盒位背景、不可移动——单线式起点在上方音轨布局窗口拖）

拖拽移动 MIDI式参考车道（其起点 = 粒子中心基准，缺省 (0,0) = 轨道 0 CB 位置）；单线式参考车道（紫、半透明）显示虚拟盒位几何、在本窗口不可拖（到音轨布局窗口拖）；普通车道（灰）与轨道 0 仅作空间参照、不可移动；参考车道不参与物理碰撞校验（MIDI式中心重叠 = 粒子有意叠放），可与普通车道任意并排
